## Reading this document

- A row marked **no** is information, not noise. It is exactly the signal that a change made
  routing worse, which is why the cases are recorded rather than improvised.
- `no agent` expectations that pass are the router refusing to answer. A router that answered
  every request would fail those rows, which is the point.
- This document records one run. It is not a scored harness result and no score is claimed.
